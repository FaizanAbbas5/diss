Motivation. Language models can take a table of data and write a short summary of it — the sort of thing that's useful for sports reports, financial updates, or weather summaries. The catch is that they often state things the table doesn't actually support, which is called hallucination. This matters most in table-to-text generation precisely because the table is a clear, checkable source of truth: unlike open-ended writing, you can verify every claim against the data, so faithfulness (the text being supported by the source) is both critical and measurable. The usual approach just hands the raw table to the model and trusts it to work out what's important and do any inference or arithmetic itself — which is exactly what models are worst at, and a common cause of errors.
Central question and aim. The project asks whether preparing the table into a more useful form before the model sees it leads to fewer hallucinations than feeding it the raw table. The idea is borrowed from systems that describe images, where a separate component first converts the image into something a language model can work with e.g. Yann LeCun's VL-JEPA. The aim is to test this fairly and measure the effect on faithfulness.
What gets built and compared. Three set-ups are compared, holding the language model, the prompt, and the settings constant so that any difference comes only from how the table was prepared. (1) A strong baseline that gives the raw table straight to the model, using careful prompting so it isn't a weak strawman. (2) The main proposal: a small network learns a compact representation of the table, and a trained adapter converts that into a form the frozen model can read — with a simpler fallback (filling the prepared information into fixed templates, which can't invent facts) if training the adapter proves too demanding. (3) An optional version that prepares the table by hand-written rules instead of a learned network, allowing a learned-versus-manual comparison. Set-ups (1) and (2) are committed; (3) is a stretch goal.
Evaluation and scope. Faithfulness is the primary measure, judged both by automatic metrics that compare the text against the table and — as the main check — by hand-labelling a sample of outputs by error type (made-up numbers, unsupported claims, contradictions, omissions). Writing quality is a secondary measure. The comparison runs across several datasets — mainly sports box scores, which are themselves a natural condensing of detailed game data — so the conclusions aren't tied to one source. Because hand-checking is slow, the plan favours covering about five datasets carefully over many superficially.
Why it's worth doing. Hallucination is the main thing stopping these systems being trusted in high-stakes settings like finance and healthcare, so reducing it on a verifiable task is a genuinely useful contribution. The approach is also attractive because it needs no retraining of the language model itself, and either of two honest outcomes — that preparing the table helps, or that it doesn't — is a valid, reportable finding.
